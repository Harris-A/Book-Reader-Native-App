# Book Reader Native App

A React Native mobile application for reading and managing books on iOS and Android — currently in early development.

##  Features (In Progress)
- Core structure set up using React Native
- Navigation between screens
- Fetching book data (e.g., from local storage or an API)
- Preconfigured development tools (TypeScript, Expo)

##  Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v14+ recommended)
- React Native CLI or Expo

### Installation
```bash
git clone https://github.com/Harris-A/Book-Reader-Native-App.git
cd Book-Reader-Native-App
npm install
# or
yarn install
```

Running the App

IOS
```bash
npx react-native run-ios
```

Android
```bash
npx react-native run-android
```

Expo (if applicable)
```bash
expo start
```
